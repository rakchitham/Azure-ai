# Microsoft Certified: Azure AI Engineer Associate (AI-102)

## About the Certification

The **Microsoft Certified: Azure AI Engineer Associate** certification validates the skills required to design, develop, implement, and manage AI solutions using Microsoft Azure AI services.

It demonstrates knowledge of building intelligent applications by integrating artificial intelligence, machine learning, natural language processing, computer vision, and generative AI capabilities into real-world solutions.

## What is Microsoft Azure AI?

Microsoft Azure AI is a collection of cloud-based artificial intelligence services provided by Microsoft Azure. These services help developers build intelligent applications without having to develop every AI model from scratch.

Azure AI provides tools and services for:
- Natural Language Processing (NLP)
- Computer Vision
- Speech Recognition and Speech Synthesis
- Generative AI
- Document Intelligence
- Knowledge Mining
- AI-powered Search
- Conversational AI and Intelligent Agents

## Key Azure AI Services

| Azure AI Service | Purpose |
|---|---|
| Azure AI Foundry | Build, customize, evaluate, and deploy AI applications and agents |
| Azure OpenAI | Integrate powerful generative AI models into applications |
| Azure AI Vision | Analyze images and extract visual information |
| Azure AI Speech | Speech-to-text, text-to-speech, and speech translation |
| Azure AI Language | Text analysis, sentiment analysis, and entity recognition |
| Azure AI Document Intelligence | Extract information from documents and forms |
| Azure AI Search | Build intelligent search and retrieval solutions |

## Skills Covered

The certification focuses on the following areas:

1. **Plan and Manage an Azure AI Solution**
   - Select appropriate Azure AI services.
   - Configure and manage AI resources.
   - Implement responsible AI practices.

2. **Implement Generative AI Solutions**
   - Work with generative AI models.
   - Build applications using Azure OpenAI.
   - Implement Retrieval-Augmented Generation (RAG).
   - Develop AI-powered applications and agents.

3. **Implement Agentic Solutions**
   - Build intelligent AI agents.
   - Integrate tools and external APIs.
   - Enable agents to perform tasks using AI models.

4. **Implement Computer Vision Solutions**
   - Image analysis and classification.
   - Optical Character Recognition (OCR).
   - Face detection and image processing.

5. **Implement Natural Language Processing Solutions**
   - Sentiment analysis.
   - Entity recognition.
   - Text classification.
   - Language understanding.

6. **Implement Knowledge Mining and Information Extraction**
   - Document processing.
   - Information extraction.
   - Intelligent search solutions.
